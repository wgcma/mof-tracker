# Movement of Funds

This is my personal project to track how funds are moved around. This project is still in development. It's following a thought I had about what is happening in the economy right now. Do we actually know how much money is being moved around?

# Areas of Focus / Data Sources

1. Government and Regulatory Filings Data
2. Financial Markets Data
3. Cryptocurrency Transactions Data

# APIs

1. Government: Financial Modeling Prep API
2. Financial: Alpha Vantage API
3. Cryptocurrency: CoinGecko API
